Stagger

My approach to Urdu type

Nastaliq set as Nastaliq

Letters keep their diagonal flow and join the way the script intends, set in a true Nastaliq typeface rather than a Naskh stand-in.

نستعلیق

Breaks that follow the verse

Lines end where the poet would pause, not where the box runs out, so the layout carries the rhythm of the couplet.

وقفہ

Legibility over decoration

The image supports the words. Contrast, size and spacing are set so the verse reads first and the artwork second.
